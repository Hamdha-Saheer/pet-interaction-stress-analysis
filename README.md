The Impact of Pet Interaction on Stress Among Pet Owners in the Western Province, Sri Lanka

Hemara Nimtharu Iddamalgoda [COHNDDS25.1F-012]

Hamdha Saheer [COHNDDS25.1F-013]

Lakshika Nimnadi [COHNDDS25.1F-014]
Institution: National Institute of Business Management (NIBM), Colombo

Project Overview
This research investigates how pet attachment influences stress levels in an urban Sri Lankan environment. By analyzing 126 valid responses from pet owners, we utilized standardized scales—the Perceived Stress Scale (PSS) and the Comfort from Companion Animal Scale (CCAS)—to determine if a significant human-animal bond correlates with lower stress.

Technical Methodology
The analysis was performed entirely in Python, using Pandas for data preprocessing and SciPy/Statsmodels for statistical validation. Key tests included:

Chi-square Tests: To compare stress levels across pet types and attachment categories.

Pearson Correlation: To check for linear relationships between comfort and stress.

Multiple Linear Regression: To evaluate if CCAS scores predict stress variance.

ANOVA: To analyze mean stress differences between different attachment groups.

Core Findings
Our statistical analysis revealed that interaction alone did not have a significant impact on stress levels for this specific demographic. While pet owners reported moderate stress, the results showed that factors like pet type or the degree of attachment did not statistically forecast stress relief. This suggests that for young adults in the Western Province, external factors—such as academic, financial, and social pressures—may have a stronger impact on stress than pet ownership.

Interactive Dashboard
A custom dashboard was developed using the Dash framework to make these findings accessible. It allows users to filter data by pet type and demographics while viewing live updates of statistical coefficients and p-values.
